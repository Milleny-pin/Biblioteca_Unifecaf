## ✨ Sobre o Projeto

A **Biblioteca Virtual** apresenta conteúdos literários de forma moderna e interativa.  
Este projeto utiliza:

- HTML5  
- CSS3  
- Modelos 3D no formato `.glb`  
- Navegação por seções  
- Layout limpo e responsivo  

---

## 🚀 Funcionalidades

### 🔍 Barra de Navegação
- Home  
- Nossos Livros  
- Unidades  
- Contatos  
- Perfil do usuário  
- Busca integrada  

### 📦 Modelos 3D Interativos
Implementação com suporte a rotação e zoom utilizando **Model Viewer**.

### 📚 Categorias Apresentadas
- Tecnologia  
- Nutrição  
- Marketing  
- Artes  
- Geografia  
- Matemática  

### 🏛️ Unidades
Cada unidade apresenta:
- imagem  
- nome  
- descrição  

### 📞 Contatos
O projeto contém:
- email institucional  
- telefone  
- endereço completo
